                     FLIGHT BOARD - QUICK START GUIDE  (v2.2)
================================================================================

WHAT IS FLIGHT BOARD?
Flight Board is an application for Microsoft Flight Simulator 2020/2024 and
X-Plane that displays a live departures and arrivals board similar to those at
real airports, but for virtual flights. It shows your flight, others on your
route, and all traffic at your departure and arrival airports.

--------------------------------------------------------------------------------
 WINDOWS APP (.EXE)
--------------------------------------------------------------------------------

SETUP (first time only):
  1. Double-click "Flight Board Setup.exe" to install
  2. Open the app from your Desktop or Start Menu
  3. Click the gear icon (top right)
  4. Enter your VATSIM CID and/or IVAO VID
  5. (Optional) Add your FSHub token and Pilot ID for landing rates
  6. Close settings - everything saves automatically

  Note: Windows may show "Smart App Control blocked an app" because the app
  isn't code-signed. This is normal for indie apps. Click "More info" ->
  "Run anyway", or right-click the .exe -> Properties -> check "Unblock".

USING THE BOARD:
  - Use the VATSIM / IVAO / FSHub toggle to switch networks
  - A small badge on each tab shows how many of your friends are online there
  - Use the Pilot / ATC toggle to switch modes
  - Connect to the network in your simulator - the board updates automatically
  - Click any flight row to see full flight-plan details and progress
  - Hover or tap the status arrow to see the full route
  - The Zulu (UTC) clock is shown in the top bar
  - Callsigns shown in ORANGE have FSHub landing-rate data available

PILOT MODE shows:
  - Your Flight (with a live progress bar under the status)
  - Flights with the Same Route
  - Friends Flying (when friends are online)
  - Airport Traffic at your departure and arrival airports

ATC MODE shows (when connected as a controller):
  - All arrivals and departures at your controlled airport
  - Your callsign and active frequency in the status bar

FSHUB VIEW shows:
  - Your latest FSHub flight and your friends' flights
  - "En route" when a friend is flying, "Arrived" with landing rate otherwise

--------------------------------------------------------------------------------
 SETTINGS (gear icon)
--------------------------------------------------------------------------------

  Network IDs      - your VATSIM CID and IVAO VID
  Airport Traffic  - show both airports, departure only, or arrival only;
                     optional IN / OUT split labels
  Time to Land     - show a live countdown instead of arrival clock time
  Progress Bar     - show/hide the flight progress bar under each status
  Multi-Monitor    - pop out Departures / Arrivals to separate windows
  FSHub Integration- token, your Pilot ID, and auto-detect of FSHub pilots
  Theme            - Dark, Light, or Custom colors (click to expand the
                     color pickers; includes a Progress Bar color)
  Friends          - add friends by name + VATSIM CID / IVAO VID / FSHub ID
                     (click the header to expand)
  My Airlines      - upload custom logos for any airline

  Tip: Custom Colors and Friends collapse by default - click their header to
  expand them and keep the Settings page compact.

  The window remembers its size, position, monitor, and maximized/full-screen
  state. Settings are saved to your Documents folder with a backup, so they
  survive app reinstalls and updates.

--------------------------------------------------------------------------------
 MULTI-MONITOR (desktop app)
--------------------------------------------------------------------------------

  In Settings -> Multi-Monitor:
  - Click "Open Departures Window" or "Open Arrivals Window" to pop that board
    out into its own window. Drag it to another monitor.
  - Each pop-out keeps the top sections (Your Flight, Same Route, Friends) plus
    only its own airport board.
  - Opening a pop-out automatically splits the view: the main window shows the
    other side, so nothing is duplicated. Closing it restores both sides.
  - Each window remembers its own position, size and monitor.

  Auto-open on startup:
  - Use the "Auto-open a window when the app starts" dropdown to have the
    Departures OR Arrivals window open automatically every launch - a hands-free
    two-monitor layout.

--------------------------------------------------------------------------------
 FSHUB INTEGRATION (landing rates)  - Windows app only
--------------------------------------------------------------------------------

  FSHub records every flight you fly and measures your landing rate.
  1. Go to fshub.io/settings/integrations and copy your API token
  2. In Flight Board: gear -> FSHub Integration -> paste the token
  3. Enter your own FSHub Pilot ID; add friends' FSHub IDs in their entries
  4. (Optional) Turn on auto-detect - the app gradually builds a database of
     FSHub pilots so landing rates appear automatically for matching traffic

  Landing rates show in the detail card of an arrived flight, color-coded
  green (soft) / amber (firm) / red (hard).

  Note: FSHub features are desktop-only. Web browsers block requests to FSHub's
  servers, so the web/PWA version covers VATSIM & IVAO only.

--------------------------------------------------------------------------------
 WEB / PWA VERSION (any device - phone, tablet, browser)
--------------------------------------------------------------------------------

URL:  https://dal0056.github.io/Flight-Board/

SETUP:
  1. Open the URL in Chrome or Edge
  2. Click gear -> enter your VATSIM CID and/or IVAO VID
  3. Your settings save automatically in the browser

INSTALL AS AN APP (optional):
  Android/Chrome:  menu -> "Add to Home Screen"
  iPhone/iPad:     Share -> "Add to Home Screen"
  Windows/Mac:     install icon in the address bar

  After an update, force-refresh (Ctrl+Shift+R) or reopen the installed app.

  NOTES:
  - VATSIM & IVAO features work fully in the web version
  - FSHub and Multi-Monitor are Windows-app only
  - Settings are saved per device

--------------------------------------------------------------------------------
 SORTING & FRIENDS
--------------------------------------------------------------------------------
  - In "Flights with Same Route" and "Airport Traffic", click a column header
    (Callsign, Airline, Route, Aircraft) to sort A-Z, again for Z-A, again to
    return to default. With IN/OUT split on, sorting works within each group.
  - Friends: gear -> Friends -> enter name + any network ID -> + Add. Online
    friends are highlighted and appear in the "Friends Flying" section, and the
    network tabs show a live count of friends online.
